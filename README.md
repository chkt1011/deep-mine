# DEEP MINE — 광산의 끝 (v12 그래픽 전면 리마스터 버전)

## Google 로그인 및 클라우드 저장 설정

계정 인증과 게임 저장에는 Firebase Authentication과 Cloud Firestore를 사용합니다.

1. [Firebase Console](https://console.firebase.google.com/)에서 프로젝트를 만들거나 기존 프로젝트를 선택합니다.
2. 프로젝트 개요 옆 **웹 앱 추가(</>)**를 눌러 앱을 등록합니다. 앱을 이미 등록했다면 **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → SDK 설정 및 구성(Config)**에서 웹 앱 설정을 확인합니다.
3. 표시된 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `firebase-config.js`의 같은 이름 항목에 복사합니다. 따옴표 안의 `YOUR_...` 예시값은 모두 실제 값으로 바꿉니다.
4. Authentication → 로그인 제공업체에서 **Google**과 **이메일/비밀번호**를 사용 설정합니다.
5. Authentication 설정의 승인된 도메인에 게임을 제공할 도메인(개발 중이면 `localhost`)을 추가합니다. `file://`로 직접 열지 말고 로컬 웹 서버나 호스팅을 사용하세요.
6. Firestore Database를 생성하고 프로젝트의 Firestore Rules에 `firestore.rules` 내용을 게시합니다. 규칙은 로그인한 사용자가 본인 UID 문서만 읽고 쓰도록 제한합니다.
7. 웹 서버에서 `index.html`을 열고 Google 또는 이메일 계정으로 로그인합니다. 계정 정보와 게임 저장은 Firestore의 `users/{사용자 UID}` 문서에 저장되며, 로그인 사용자의 이메일과 표시 이름도 함께 기록됩니다.

이전 버전의 브라우저 저장 데이터는 같은 브라우저에서 기존 Google 이메일과 일치하는 경우 첫 로그인 시 가져옵니다. 새 로그인 후에는 브라우저 로컬 저장과 Firestore에 자동 저장됩니다. 이 게임은 클라이언트에서 게임 상태를 계산하므로, 경쟁형 멀티플레이의 치트 방지나 실시간 게임 서버 기능은 별도로 구현해야 합니다.

## 🎨 그래픽 리마스터 개선 사항

1. **다각형 바위 & 결정체 광석 도트 아트**
   - 단순한 단색 사각형 위에 이모지만 띄우던 밋밋한 렌더링을 완전히 제거했습니다.
   - 바위 그림자, 입체 암반 덩어리, 광물별 고유 원석 결정체(`mainColor` + `veinColor` 광택 하이라이트)와 희귀 등급 오라 파동이 세밀하게 그려집니다.

2. **입체 지형 타일 & 바닥 디테일**
   - 44px 고밀도 그리드에 체스판 패턴 바닥 질감, 입체 암벽 단차, 지하 발광 버섯 및 작은 자갈 데코레이션을 추가했습니다.

3. **정교한 2등신 도트 광부 캐릭터**
   - 걷기 다리 모션, 작업복과 황금 버클 벨트, 전조등 안전모, 좌우 시선 전환과 곡괭이 스윙 애니메이션이 적용되었습니다.
